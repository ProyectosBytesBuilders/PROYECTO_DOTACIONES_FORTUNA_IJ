# PROYECTO_DOTACIONES_FORTUNA_IJ
Este proyecto tiene el fin de crear un sistema de información semi-automatizado para Dotaciones_Fortuna_IJ mejorando la trazabilidad en tiempo real y mejorando los procesos internos y externos de la empresa dando solucion y eliminando todos los procesos manuales manejados actualmente, este repositorio contiene la documentación con su respectivo vesionamiento necesario para que el proyecto logre llevarse a cabo.
